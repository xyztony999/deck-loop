## 第一部分：文档概述

将 deck-loop 业务架构（BA v1.0）映射为应用域（DDD 四层）→ 功能模块 → 功能子模块的结构，标注用户类型与模块调用关系；并补充 BA 不涵盖的系统级功能（AI 生成网关、账号与设备同步）。

### 1.1 背景与目标

deck-loop 为「AI 生成 + 语言迭代」内容创作客户端（Vue3 桌面端 + Node/TypeScript 云端服务：宝塔 Node 项目部署，Docker Compose 备选）。本架构以**语言迭代闭环**为业务主链组织功能，核心域围绕「创作物—版本树—调整指令」深建模型；素材/话术/演示为支撑能力；AI 网关与账号同步为平台技术能力。

> **持久层技术注记（ADR-016，2026-11-24）**：云端持久层由 MongoDB（mongoose）全量迁移至 **PostgreSQL（TypeORM，@nestjs/typeorm + pg）**，与用户另一项目 UniGate **共用同一 PG 实例、不同 database**（deck-loop 用 `deck_loop` 库），以在 1.6 G 内存服务器上只运行一个数据库进程（目标净省 200–300 MB）。**应用域/功能模块/功能子模块的业务结构零变化**——本注记仅为实现层技术栈变更：业务主键（雪花串）升为表主键、原 Mixed 嵌入快照改 jsonb 列、Mongo aggregate 改 SQL、多文档事务改 PG 原生事务（版本留档恢复单事务）。**对外 API 契约与客户端零变化**（66 端点冻结）。栈依赖：运行时移除 @nestjs/mongoose/mongoose，新增 @nestjs/typeorm/typeorm/pg；后端栈实质由 `node-nestjs-mongo` 变为 `node-nestjs-psql`（profile depends 键改名留待用户确认）。详见 `00-architecture/ADR-016-persistence-mongo-to-psql.md` 与 06 规约 v1.2 增补节。

> **架构重定向注记（ADR-018，2026-11-25，web-mgmt-20261125）**：云端 PG 为唯一权威
> 数据源（网站与远程 MCP 直读直写）；**AI 网关彻底移除**——C-02 初稿生成、C-03 语言
> 调整、D-01 AI 渠道与偏好、P-01 AI 生成网关四模块退役（编码保留不复用），AI 产出

> VersionArchiveService 唯一写入口）；大纲保存能力迁 C-01（/deck/deck/outline-save）。
> P-02 保留并新增「个人 API token」子模块（MCP 远程鉴权，独立守卫）；数据同步服务
> 对象收窄为 MCP 本地离线模式（网站/远程 MCP 不经同步）。**Web 管理站**（web/，
> 779f3d6 历史恢复剥 Tauri）为新增客户端形态：素材/Deck/版本树/预览放映/导出下载
> 四功能组，浏览器侧渲染（ADR-015 服务端零渲染不变）。端点口径 75→56（移除 23、
> 迁移 1、新增 4），契约冻结解除以 ADR-018 为据。详见
> `00-architecture/ADR-018-web-single-source.md` 与 02-detailed/api/api-web-agent.md。

## 第二部分：应用架构

> 本章按应用域逐层描述功能模块与功能子模块。每个应用域有其概述，每个功能模块/子模块有功能说明及涉及用户类型。

### 本架构概览

核心业务域承载「创作物生命周期 + 生成/调整主链 + 版本树 + 定稿交付闭环」；支撑业务域提供素材品牌、话术、演示三类支撑能力；基础数据域承载 AI 渠道偏好这一系统级引用数据；平台支撑域补充 BA 不涵盖的纯技术能力（AI 生成网关、账号与设备同步）。创作物状态机（草稿→迭代中→已定稿→已归档）与版本不可变性是全架构两条核心业务不变量。

| 分层 | 说明 | 包含功能模块 |
|------|------|-------------|
| 核心业务域 | 承载核心业务价值，有状态机和聚合根，深度建模 | 创作物管理(C-01)、~~初稿生成(C-02)~~（退役 v1.4）、~~语言调整(C-03)~~（退役 v1.4）、版本管理(C-04，+agent 直写留档)、定稿管理(C-05)、导出交付(C-06) |

| 基础数据域 | 系统级引用数据，无业务状态机，薄适配 | ~~AI 渠道与偏好(D-01)~~（退役 v1.4，本分层空） |
| 平台支撑域 | 纯技术能力，零业务语义，可复用 | ~~AI 生成网关(P-01)~~（退役 v1.4）、账号与设备同步(P-02，+个人 API token) |
