# 07 — UI 设计语言规范（唯一权威）

| 属性 | 值 |
|------|-----|
| 版本 | v2.0 |
| 状态 | 稳定（2026-10-22「推倒重来」定案：单表面形态语言） |
| 适用 | client 全部视图与引擎组件；新页面必须沿用 |
| 关联 | theme.ts（Antd token）/ global.less（CSS 变量）/ ui-rebuild-2026-10-22.md（逐页处方） |

> 本规范是 deck-loop 客户端界面的**唯一**设计语言。任何视图样式与本规范冲突时，以本规范为准。
> 基调（用户定调，不复议）：**单一分层语言；厌恶卡中卡与多种黑；蓝只作 accent。**
> v2.0 形态定调（2026-10-22 三分叉拍板）：**紧凑工具型（Linear/Notion 方向）——单表面 + 细分隔线代替卡片堆叠，筛选内嵌工具栏，密度紧凑。**

---

## 1. 两个表面域（最重要的分域规则）

| 表面域 | 定义 | 色彩语言 | 适用位置 |
|--------|------|---------|---------|
| **应用 chrome** | 一切界面框架与操作控件 | 暗色三层色板（§2），跟随主题 | 页面壳、侧栏、顶栏、工具条、弹窗、表单、表格、列表、树、抽屉、菜单 |
| **文档表面** | 幻灯片内容的渲染载体 | **永远白纸**（`--dl-doc-bg`），不随主题、不加暗色滤镜 | 幻灯片预览画布（DeckPreviewCanvas 内框）、演示舞台幻灯片区（present stage 内框）、导出渲染窗口画布 |

**判定法**：用户在"操作软件"还是在"看文档内容"？操作软件 → chrome；看文档 → 文档表面。
**画布外围的控件**（缩放条、翻页器、工具按钮）永远属 chrome。

## 2. 色彩

### 2.1 暗色三层色板（唯一基准，亮色维持现状不动）
| 层 | 值 | 变量 | v2.0 用法 |
|----|----|------|----------|
| 页面底 | #141414 | `--dl-bg-page` / Antd `colorBgLayout` | **侧栏底色**、裸页（登录/演示）背景、遮罩基座 |
| 表面 | #1f1f1f | `--dl-card-bg` / Antd `colorBgContainer` | **页面内容表面**（贴壳满幅单表面，§3）、顶栏、表格 |
| 浮层 | #262626 | Antd `colorBgElevated` | 弹窗/下拉/抽屉/悬浮面板 |

三层各司其职：暗侧栏（页面底）→ 亮内容（表面）→ 更亮浮层。**主内容区不再出现"表面色卡片浮在页面底上"的堆叠。**

### 2.2 主色与语义色（禁止硬编码）
| 语义 | 来源 | 禁止出现的写法 |
|------|------|--------------|
| 主色/accent | `#6b8ab5`（经 Antd token / `--dl-primary` 引用，不自写 hex） | ~~#1890ff~~ ~~#1677ff~~（历史杂蓝，全数替换） |
| 成功 | Antd success token | ~~#52c41a~~ |
| 警告 | Antd warning token | ~~#faad14~~ 直写 |
| 危险 | Antd error token / `--dl-danger-color` | ~~#ff4d4f~~ 直写 |
| 次要文字 | `--dl-text-secondary` | ~~#6b7280~~ ~~#9ca3af~~ 直写 |
| 边框 | `--dl-border-light` / Antd border token | ~~#d1d5db~~ 直写 |
| 滚动条 | `--dl-scrollbar`（暗 #3f4450 / 亮 #c4c9d2） | 原生默认滚动条（**v2.0 头号违例**，见 §7） |
| 文档底 | `--dl-doc-bg: #fff` | 画布内可直接用变量 |

**规则**：chrome 域内出现任何 hex 色值即违规（审计脚本按此巡检）；文档表面域内允许有限内容色（见 §6）。

### 2.3 蓝的用法
蓝**只作 accent**：主操作按钮、链接、选中态、焦点、进度、tile hover 描边。禁止用作大面积背景、装饰条、图标堆染。~~卡片标题蓝竖条~~（v2.0 废除）。

## 3. 形态语言（v2.0 核心：单表面原则）

### 3.1 单表面原则
- **每页一个连续表面**：内容区（`.dl-content`）即表面（#1f1f1f），贴壳满幅、无外边距、无圆角；页面内部**禁止堆叠第二层表面卡片**（`dl-page-card` 已废除）。
- **分区 = 分隔线 + 小节标题**：1px `--dl-border-light` 分隔线；小节标题为纯文字（13px/600），**无竖条、无底边框、无背景块**。
- 侧栏坐页面底（#141414）与内容表面形成明暗分层；顶栏属内容表面，以底部分隔线与内容分界。

### 3.2 列表页解剖（自上而下）
```
┌─ 表面 ──────────────────────────────────────────┐
│ 页头行  padding 16/24：标题(15/600) … [筛选字段内联] [次操作] [主操作(primary)] │
├─ 1px 分隔线 ────────────────────────────────────┤
│ 选择条（仅 rowSelection 且已勾选时出现）padding 8/24：已选 N 项 + 批量操作    │
├─────────────────────────────────────────────────┤
│ 平铺表格（无内嵌卡片、无横向滚动；表头透明）        │
├─ 1px 分隔线 ────────────────────────────────────┤
│ 页脚行  padding 12/24：共 N 条 …… 分页器(small)   │
└─────────────────────────────────────────────────┘
```
- **筛选内嵌页头**：select/dateRange 变更即查询；input 回车或清空即查询；**废除「查询/重置」按钮组**；存在激活筛选时页头出现重置图标（ghost）。筛选字段 >4 时允许换行（flex-wrap）。
- 主操作（create）为页头 primary；次操作为页头 default/ghost；页面级特有控件（如归档开关、远程搜索选择）经引擎 `#header-extra` 槽进入页头。

### 3.3 向导页解剖
```
┌─ 表面 ──────────────────────────────────────────┐
│ 向导栏(sticky) padding 12/24：标题(15/600) · 内联步骤条 … 取消|上一步|暂存|下一步(primary) │
├─ 1px 分隔线 ────────────────────────────────────┤
│ 内容区 padding 24，max-width 860 居中：            │
│   小节 = 小节标题(13/600) + 内容；小节间距 24       │
└─────────────────────────────────────────────────┘
```
- **内联文字步骤条**替代整卡 a-steps：编号小圆点（18px 描边圆；当前=主色描边+主色文字；已完成=主色 ✓；未到=次要色）+ 步骤名（13px；当前 600），步骤间用细箭头/斜杠分隔。
- 暂存按钮仅在 config 声明 `saveDraftAction` 时出现。
- 表单网格 2 列（860 容器内）；textarea/upload 独占整行。

### 3.4 详情/设置页解剖
同小节语言：页头行（标题+操作）+ 分隔线 + 小节流。设置页 Tab 坐表面顶部（下划线式），Tab 内为小节流。

### 3.5 卡片视图（tile 规范）
列表卡片视图 = **描边 tile**：1px `--dl-border-light` 边框、radius 8、背景透明、padding 12；hover：边框转主色 45% 透明描边 + 轻微浮起。tile 是"内容物件"（Notion database 卡），不是 chrome 容器。

## 4. 圆角
| 值 | 用途 |
|----|------|
| 0 | **页面表面**（贴壳满幅，无圆角） |
| 4px | 标签、小徽标、行内小块 |
| 8px | 控件（Antd token）、tile、tile 内图框 |
| 10px | 浮层（弹窗/悬浮面板）、画布外框 |

**废除**：2/3/6/12px 圆角；~~卡片 10px 圆角+阴影浮起~~（v2.0 表面无卡片）。

## 5. 间距标尺（4px 基数）
| 档位 | v2.0 锚点 |
|------|----------|
| 4 / 8 | 图标与文字、行内元素、tile 网格 gap（12 见下）、表头单元格上下 |
| 12 | 表格单元格上下 padding、紧凑列表项、选择条上下 |
| 16 | **默认档**：页头上下、小节标题下缘、单元格左右（16） |
| 24 | 页头/页脚/单元格左右（与 16 按轴向分工）、小节间距、内容区 padding |
| 32+ | 裸页仪式性留白 |

**规则**：padding/margin/gap 取标尺值；非标组合全数归并到视觉最近档。

## 6. 字号阶梯
| 档 | 值 | 用途 |
|----|----|------|
| 表格正文 | 13px | 表格单元格 |
| 正文 | 14px（Antd token） | 默认 |
| 辅助/表头 | 12px | 说明文字、meta、表头（次要色） |
| 小节标题 | 13px/600 | 小节、tile 标题 |
| 页面标题 | 15px/600 | 页头、向导栏 |

## 7. 表格与滚动条规范（v2.0 头号修复项）
- **禁横向 `max-content` 滚动**：表格不设 `scroll.x`，列宽仅作分配权重，内容溢出走省略号；由此消灭原生横向滚动条（暗色下的亮白条 = 「卡片长出来」事故根因）与空表滚动条。
- **固定列分界线禁用**：无横向滚动后取消 `fixed` 强制；`.ant-table-cell-fix-right-last::after` 阴影线一律隐藏。
- 表头：透明背景（坐表面）、12px/次要色/500、底 1px 分隔线；**禁**表头独立底色块。
- 单元格：13px、padding 12px 16px；行 hover `--dl-hover-bg`；斑马纹禁用。
- 操作列：ghost 文字按钮（link 型，无底），>2 个收进「更多」。
- **滚动条全站规范**（所有滚动容器，含侧栏/页内/弹窗/代码区）：
  `scrollbar-width: thin; scrollbar-color: var(--dl-scrollbar) transparent;`
  webkit：8px 轨道（透明）+ 4px 可视拇指（`--dl-scrollbar`、radius 4、2px 透明 border 内缩）。出现原生默认滚动条即违例。

## 8. 筛选交互规范
见 §3.2：变更即查、废除查询/重置按钮组、激活筛选出重置图标。dateRange 清空也触发查询。防抖仅用于输入型字段的逐键场景（当前无）。

## 9. 组件用法规则
- **页面内禁止第二层表面卡片**（v1.0「禁卡中卡」升级）：分组一律分隔线+小节标题；唯一例外 = §3.5 tile（内容物件）与浮层（弹窗/抽屉，坐第三层）。
- 表格/表单/列表/向导一律走引擎组件（DlListPage/DlCardPage/DlDetailPage）v2 形态；视图只做槽内容定制，不得自造页头/查询区。
- 弹窗用 Antd Modal/Drawer（浮层层）；自定义仅限布局，不得自带色板。
- 控件密度：工具栏/筛选控件 `size="small"`（28px）；页头主操作 32px。

## 10. 巡检口径
- chrome 域 `#[0-9a-f]{3,8}` hex 直写 = 违规（文档表面域除外，且仅限 §6 白名单）。
- border-radius ∈ {0, 4, 8, 10}px。
- padding/margin/gap ∈ {4, 8, 12, 16, 24, 32, 48, 64, 96}。
- `scroll.*x.*max-content` = 违规；`dl-page-card` / `dl-sticky-bar` 类残留 = 违规；卡片标题竖条（`dl-card-title::before`）= 违规。
- 出现未按 §7 规范的滚动条 = 违例。
