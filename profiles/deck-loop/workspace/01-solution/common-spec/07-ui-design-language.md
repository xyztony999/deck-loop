# 07 — UI 设计语言规范（唯一权威）

| 属性 | 值 |
|------|-----|
| 版本 | v1.0 |
| 状态 | 稳定（2026-10-21 UI 统一重设计定案） |
| 适用 | client 全部视图与引擎组件；新页面必须沿用 |
| 关联 | theme.ts（Antd token）/ global.less（CSS 变量）/ D0-ui-unify-2026-10-21.md |

> 本规范是 deck-loop 客户端界面的**唯一**设计语言。任何视图样式与本规范冲突时，以本规范为准。
> 基调（用户定调，不复议）：**单一分层语言；厌恶卡中卡与多种黑；蓝只作 accent。**

---

## 1. 两个表面域（最重要的分域规则）

| 表面域 | 定义 | 色彩语言 | 适用位置 |
|--------|------|---------|---------|
| **应用 chrome** | 一切界面框架与操作控件 | 暗色三层色板（§2），跟随主题 | 页面壳、侧栏、顶栏、工具条、弹窗、表单、表格、列表、树、抽屉、菜单 |
| **文档表面** | 幻灯片内容的渲染载体 | **永远白纸**（`--dl-doc-bg`），不随主题、不加暗色滤镜 | 幻灯片预览画布（DeckPreviewCanvas 内框）、演示舞台幻灯片区（present stage 内框）、导出渲染窗口画布 |

**判定法**：用户在"操作软件"还是在"看文档内容"？操作软件 → chrome；看文档 → 文档表面。
**画布外围的控件**（缩放条、翻页器、工具按钮）永远属 chrome——此前 present.vue 整页写死亮色、DeckPreviewCanvas 控件混亮色，均属违反本条。

## 2. 色彩

### 2.1 暗色三层色板（唯一基准，亮色维持现状不动）
| 层 | 值 | 变量 | 用途 |
|----|----|------|------|
| 页面底 | #141414 | `--dl-bg-page` / Antd `colorBgLayout` | 应用背景 |
| 表面 | #1f1f1f | `--dl-card-bg` / Antd `colorBgContainer` | 卡片/面板/表格 |
| 浮层 | #262626 | Antd `colorBgElevated` | 弹窗/下拉/抽屉 |

### 2.2 主色与语义色（禁止硬编码）
| 语义 | 来源 | 禁止出现的写法 |
|------|------|--------------|
| 主色/accent | `#6b8ab5`（经 Antd token 引用，不自写 hex） | ~~#1890ff~~ ~~#1677ff~~（历史杂蓝，全数替换） |
| 成功 | Antd success token | ~~#52c41a~~ |
| 警告 | Antd warning token | ~~#faad14~~ |
| 危险 | Antd error token / `--dl-danger-color` | ~~#ff4d4f~~ 直写 |
| 次要文字 | `--dl-text-secondary` | ~~#6b7280~~ ~~#9ca3af~~ 直写 |
| 边框 | `--dl-border-light` / Antd border token | ~~#d1d5db~~ ~~#f0f0f0~~ 直写 |
| 文档底 | `--dl-doc-bg: #fff`（新增变量，文档表面专用） | 画布内可直接用变量 |

**规则**：chrome 域内出现任何 hex 色值即违规（审计脚本按此巡检）；文档表面域内允许有限内容色（见 §6）。

### 2.3 蓝的用法
蓝**只作 accent**：主操作按钮、链接、选中态、焦点、进度。禁止用作大面积背景、装饰条、图标堆染。

## 3. 圆角（三值制）
| 值 | 变量/来源 | 用途 |
|----|----------|------|
| 4px | 直写 | 标签、小徽标、行内小块 |
| 8px | Antd `borderRadius` token | 按钮等控件（Antd 自带）、输入框、下拉 |
| 10px | `--dl-card-radius` | 卡片、面板、画布外框 |

**废除**：2/3/6/12px 圆角（存量全数归并到最近档）。

## 4. 间距标尺（4px 基数）
| 档位 | 用途 |
|------|------|
| 4 / 8 | 图标与文字、行内元素 |
| 12 | 组内元素、紧凑列表项 |
| 16 | **页面内边距、卡片内边距、区块间距（默认档）** |
| 24 | 大区块之间、弹窗 body |
| 32+ | 页面级留白（登录页等仪式性页面） |

**规则**：padding/margin/gap 取标尺值；`12px 14px`、`10px 20px` 等非标组合全数归并（14→16 或 12，10→8 或 12，按视觉最近档）。

## 5. 字号阶梯
| 档 | 值 | 用途 |
|----|----|------|
| 正文 | 14px（Antd token） | 默认 |
| 辅助 | 12px | 说明文字、meta |
| 区块标题 | 15-16px/500 | 卡片标题 |
| 页面标题 | 18-20px/600 | 页面主标题 |

## 6. 文档表面域的内容色（有限白名单）
幻灯片画布内允许：白底 `--dl-doc-bg`、内容文字深灰（render-template.ts 既有内容配色体系）、内容块强调色沿用渲染模板（与导出/演示共享 render-template.ts 单一来源）。**chrome 色板不得渗入画布内容，画布内容色不得漂出到 chrome。**

## 7. 组件用法规则
- **禁卡中卡**：表面层内不得再嵌"表面卡片"做分组——同层分组用间距 + 分隔线（`--dl-border-light`）或小节标题，不用第二层 Card。
- 表格/表单/列表一律走引擎组件（DlListPage/DlCardPage/DlDetailPage）默认密度；视图只做槽内容定制。
- 弹窗用 Antd Modal/Drawer 默认（浮层层），自定义弹窗样式仅限布局，不得自带色板。
- 页面骨架三段式：标题区（页名+主操作）/ 工具栏（筛选/次操作）/ 内容区；由引擎提供壳，视图不得自造页头。

## 8. 巡检口径
- chrome 域 `#[0-9a-f]{3,8}` hex 直写 = 违规（文档表面域除外，且仅限 §6 白名单）。
- border-radius ∈ {4, 8, 10}px。
- padding/margin/gap ∈ {4, 8, 12, 16, 24, 32, 48, 64, 96}。
