# PageSpec — 登录/注册（客户端入口）

| 属性 | 值 |
|------|-----|
| 模块编码 | P-02（auth 用户可见入口，平台支撑域） |
| 用户类型 | creator |
| 业务类型 | 平台入口（无业务单据） |
| 页面类型 | code（独立全屏轻页） |
| 路由 | /auth（登录/注册切换） |
| 版本 | v1.2（2026-10-08） |
| 输入 | api-platform.md v1.2 |

## 1. 模块元信息

- App：客户端未登录态唯一可达页；登录成功 → /deck。

## 2. Action 定义

| action key | 方法 | 路径 | 说明 |
|-----------|------|------|------|
| login | POST | /auth/account/login | 登录 |
| register | POST | /auth/account/register | 注册 |

## 3. 页面结构（code 轻表单）

| 模式 | 字段 | 校验 |
|------|------|------|
| 登录 | email · password | 格式校验；失败计数提示（5 次锁 10 分钟，BIZ_AUTH_CREDENTIALS 文案透传） |
| 注册 | email · password(≥8) · nickname | email 唯一（BIZ_AUTH_EMAIL_EXISTS 定位字段错误） |

按钮：登录/注册（切换链接）。成功：token 持久化（本地安全存储）→ 首次进入触发一次 sync_pull。

## 4. 路由定义

| 路由 | 页面 | 守卫 |
|------|------|------|
| /auth | 登录/注册 | 未登录；已登录访问 → 重定向 /deck |

## 5. 全局一致性

- 全局路由守卫：无 token 一律重定向 /auth；401（BIZ_AUTH_SESSION_EXPIRED）全局拦截清态回登录页。
- 会话 30 天滑动，客户端启动静默续期。
