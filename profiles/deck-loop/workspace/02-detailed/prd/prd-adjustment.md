# PRD — 语言调整（C-03）

| 属性 | 值 |
|------|-----|
| 模块 | C-03 语言调整（AA v1.0） |
| 功能类型 | 业务流程类（异步任务驱动，产品核心） |
| 版本 | v1.1 |
| 日期 | 2026-10-08 |

## 1. 业务目标（G1）

把「只能靠语言微调」的聊天式体验产品化：整稿级与定向局部级的自然语言调整指令，每次调整自动留档为版本。为创作者提供精确、可追溯的修改手段。

## 2. 功能范围（G2）

**做**：整稿调整指令（风格/结构/篇幅/受众）；定向调整——目标选取（页/文本块/图片元素）+ 局部指令 + 品牌约束开关；话术模板选用与收藏；指令下达后的任务跟踪。

**不做**：手动拖拽/直接编辑内容；批量多目标指令（首期单目标）；对 FAILED 历史版本的调整（仅可对树内任意版本发起，等价分叉语义）。

## 3. 角色（G3）

创作者：选取目标、编写指令、选用话术、发起与跟踪。

## 4. 领域对象与关系（G4/G5）

- 调整指令（值对象，随任务与版本快照留存）：instructionText、scope（TARGETED 时=目标定位路径）、brandKitId、usedTemplateIds。
- GenerationTask（子流程）：taskType=FULL_ADJUST / TARGETED_ADJUST。
- 产出：新 DeckVersion（parent=发起时基线版本）。

## 5. 业务字段（T1）

| 字段 | 说明 | 约束 |
|------|------|------|
| instructionText | 调整指令文本 | 必填 ≤2000 字 |
| baseVersionId | 基线版本 | 必填=发起时浏览/指定的版本（默认当前版本） |
| scope.targetKind | 目标类型 | 枚举 PAGE / TEXT_BLOCK / IMAGE_BLOCK（FULL_ADJUST 无） |
| scope.targetPath | 目标定位 | 页ID 或 页ID+块ID |
| applyBrandKit | 是否应用品牌约束 | 布尔；true 时 brandKitId 必填（默认取 Deck 默认规范） |
| usedTemplateIds | 引用话术模板 | 可空数组 |

## 6. 被引用关系（T1a）

新版本被 Deck.currentVersionId/版本树引用；指令快照被版本详情展示引用。

## 7. 状态流转（T2）

同任务状态机（§prd-generation T2）；成功→新版本留档→当前指针前移（同分支）；基线≠当前版本时成功→新版本落于基线之下（等效分叉，提示用户命名分支）。

## 8. 业务规则

1. 仅 ITERATING 态可发起调整（FINALIZED/ARCHIVED 拒绝）。
2. 定向调整仅变更目标作用域，未涉及页面必须逐字节保持（一致性校验在任务产出校验中执行，不一致回退为 FAILED）。
3. 同一创作物同时最多 1 个进行中任务。
4. 品牌约束开启时，生成提示注入品牌规范（色板/字体/logo 约束文本）。
5. 发起时必须显示基线版本号，避免「改错版本」。
6. 话术模板占位符在提交前完成替换校验。

## 9. 非功能与异常（N1/N2）

- 定向调整预期 <60s；整稿调整 30s~3min。
- 目标定位失效（版本切换后页/块ID不存在）→ 提交前校验拦截。
- provider 失败重试同 prd-generation §9。

## 10. 历史与审计（N4）

指令全文随版本快照不可变留存；「收藏本次指令为话术」记录模板来源。
