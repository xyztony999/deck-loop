# PRD — 素材与品牌资产管理 · 迭代话术库（S-01 / S-02）

| 属性 | 值 |
|------|-----|
| 模块 | S-01 素材与品牌资产管理、S-02 迭代话术库（AA v1.0） |
| 功能类型 | 主数据类（启停生命周期） |
| 版本 | v1.1 |
| 日期 | 2026-10-08 |

## 1. 业务目标（G1）

为生成与调整供给一致性资产：素材（图片/logo）与品牌规范（色板/字体/标志）保障多版本内容风格统一；话术库沉淀有效调整话术降低表达门槛。

## 2. 功能范围（G2）

**做**：素材上传/分类/检索/重命名/停用恢复；品牌规范多套维护（色板/字体组/标志）与默认套设置；话术模板收藏/编辑/分类/场景标注；指令输入时选用与「收藏本次指令」。

**不做**：素材在线裁剪编辑；字体文件上传（首期用预置字体名清单）；话术模板分享市场。

## 3. 角色（G3）

创作者：全部操作。

## 4. 领域对象与关系（G4/G5）

聚合根：Asset、BrandKit（1 BrandKit → 1 logo Asset 引用）、PromptTemplate。见 domain-model.md §3。

## 5. 业务字段（T1）

**素材 Asset**：assetName、category、storageKey、assetType（IMAGE/LOGO）、width/height、assetStatus(ACTIVE/DISABLED)、refCount（被引用统计）。

**品牌规范 BrandKit**：kitName、colors（色板数组，主色+辅色）、fonts（标题/正文字体名）、logoAssetId、isDefault。

**话术模板 PromptTemplate**：title、content（含 {占位符}）、category、templateScene（WHOLE/TARGETED 通用场景标签）、useCount。

## 6. 被引用关系（T1a）

被生成/调整/导出/演示模块经 ID 引用（domain-model.md §6）。

## 7. 状态流转

无业务状态机；素材/规范为启停生命周期（ACTIVE/DISABLED）。

## 8. 业务规则

1. 被版本快照引用的素材/规范**不可删除，仅可停用**（ADR-004）；停用项不再出现在生成引用选择器。
2. 默认规范唯一；删除默认规范前必须先转移默认。
3. 上传限制：单文件 ≤10MB；类型 jpg/png/svg/webp。
4. 话术占位符格式 {名称}，使用时前端校验全部替换。
5. 「收藏本次指令为话术」自动带场景标签（按指令 scope 类型）。

## 9. 非功能与异常（N1/N2）

- 素材量级 ≤ 数百；缩略图生成。
- 上传失败重试；重复文件（同 hash）提示复用已有素材。

## 10. 历史与审计（N4）

停用/恢复操作日志；话术 useCount 统计。
