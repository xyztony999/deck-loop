# PRD — AI 渠道与偏好（D-01）

| 属性 | 值 |
|------|-----|
| 模块 | D-01 AI 渠道与偏好（AA v1.0） |
| 功能类型 | 主数据类（用户级配置，薄） |
| 版本 | v1.1 |
| 日期 | 2026-10-08 |

## 1. 业务目标（G1）

让创作者按成本/质量权衡配置生成资源：默认渠道与分任务类型的模型档位；透明可见的用量统计。

## 2. 功能范围（G2）

**做**：渠道与模型偏好设置（默认渠道；大纲/整稿/定向三类任务档位）；用量统计查看（渠道/创作物/时间维度）。

**不做**：渠道接入管理（平台侧，P-01）；密钥管理（不暴露给用户）；用量计费/充值。

## 3. 角色（G3）

创作者：设置与查看。

## 4. 领域对象与关系（G4/G5）

聚合根「渠道偏好 ChannelPreference」（用户 1:1）；关联领域对象 ChannelModel（AI 网关域，只读清单）；用量数据来源于网关域 UsageRecord。

## 5. 业务字段（T1）

| 字段 | 说明 | 约束 |
|------|------|------|
| userId | 用户 | 1:1 |
| defaultChannelCode / defaultModelCode | 默认渠道/模型 | 必填（有可用渠道时） |
| preferenceMap | 分任务档位 | JSON：{OUTLINE: {channel,model}, FULL_GENERATE: …, FULL_ADJUST: …, TARGETED_ADJUST: …}，缺省回落默认 |

## 6. 被引用关系（T1a）

被生成/调整任务路由时读取；被网关域用作路由输入。

## 7. 状态流转

无状态机（配置数据）。

## 8. 业务规则

1. 仅可选择网关下发为可用（enabled）状态的渠道/模型。
2. 档位未配置的任务类型回落默认渠道/模型。
3. 渠道下线（网关标记停用）后：存量偏好保留但标记不可用并提示改选；任务路由自动降级到默认可用渠道并告警。
4. 用量统计口径=网关计量记录（token/次数），T+0 实时聚合。

## 9. 非功能（N1）

统计查询时间范围 ≤12 个月，聚合查询 <2s。

## 10. 历史与审计（N4）

偏好变更记录操作日志。
