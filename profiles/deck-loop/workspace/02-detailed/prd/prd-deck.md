# PRD — 创作物管理与定稿（C-01 / C-05）

| 属性 | 值 |
|------|-----|
| 模块 | C-01 创作物管理、C-05 定稿管理（AA v1.0） |
| 功能类型 | 业务流程类（状态机驱动） |
| 版本 | v1.2 |
| 日期 | 2026-10-08 |

## 1. 业务目标（G1）

为「AI 生成 + 语言迭代」提供项目化载体：以创作物为单位组织一次内容创作的需求、版本谱系与状态；并管理定稿锁定/解锁，使交付有明确锚点。价值对象：创作者。

## 2. 功能范围（G2）

**做**：创作物创建（类型选择，首期仅演示文稿）、信息编辑、列表检索、归档/恢复、状态机管理（草稿/迭代中/已定稿/已归档）、定稿标记与锁定、解锁恢复编辑、当前版本指针维护。

**不做**：多用户协作/分享；手动像素级内容编辑（内容变更一律经生成/调整任务）；文档/海报类型的实际落地（仅类型枚举预留）。

## 3. 角色（G3）

创作者：全部操作；无审批角色（个人产品，定稿为自确认操作，非审批）。

## 4. 领域对象与关系（G4/G5）

聚合根「创作物 Deck」；关联：1 Deck → N DeckVersion（版本管理模块）、1 Deck → 0..1 BrandKit（默认规范）。详见 domain-model.md §2。

## 5. 业务字段（T1）

| 字段 | 说明 | 约束 |
|------|------|------|
| deckName | 创作物名称 | 必填，≤100 字 |
| deckType | 内容类型 | 枚举 DECK（首期唯一，预留 DOC/POSTER） |
| topic | 主题 | 必填，≤200 字 |
| requirement | 需求描述 | 可空，长文本 |
| defaultBrandKitId | 默认品牌规范 | 可空，引用素材品牌域 |
| deckStatus | 状态 | 枚举 DRAFT/ITERATING/FINALIZED/ARCHIVED |
| currentVersionId | 当前版本指针 | 指向本创作物版本树内版本；DRAFT 态为空 |
| activeBranch | 活动分支名 | 默认 main；分叉后可切换 |
| finalVersionId | 定稿版本 | FINALIZED 态必有值 |

## 6. 被引用关系（T1a）

被初稿生成/语言调整/导出交付/演示放映引用（deckId）；被版本管理模块作为树根。

## 7. 状态流转（T2）

见 domain-model.md §4.1（含守卫：FINALIZED 禁止发起任务；归档/定稿要求无进行中生成任务）。

## 8. 业务规则

1. 调整与生成仅可由语言指令经任务驱动（定位约束）。
2. 删除创作物=归档后软删除，连带版本树不可再访问；已定稿项归档保留导出记录可追溯。
3. 解锁定稿后创作物回 ITERATING，后续调整产生新版本（历史不动）。
4. deckType 首期仅开放 DECK，其余类型选项置灰并标注「即将支持」。

## 9. 非功能与异常（N1/N2）

- 个人量级：单用户创作物 ≤ 数百，版本 ≤ 数千/创作物；列表分页。
- 状态守卫冲突（定稿时有进行中任务）→ 明确报错并引导至任务面板。
- 网络离线时创作物列表可读（本地缓存），写操作在线完成。

## 10. 历史与审计（N4）

状态流转与定稿/解锁/归档操作记录操作日志。
