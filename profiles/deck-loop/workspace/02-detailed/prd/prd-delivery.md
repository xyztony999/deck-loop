# PRD — 导出交付与演示放映（C-06 / S-03）

| 属性 | 值 |
|------|-----|
| 模块 | C-06 导出交付、S-03 演示放映（AA v1.0） |
| 功能类型 | 业务流程类（导出任务）+ 只读放映 |
| 版本 | v1.2 |
| 日期 | 2026-10-20 |

## 1. 业务目标（G1）

把定稿版本交付为可用成品：**客户端渲染**多格式导出（PDF/图片为主路径，可编辑 PPTX 为增强目标；产物回传云端台账，多端可下载）+ 客户端内全屏演示（渲染源与导出同源，所见即所得）。让闭环终点顺滑。

## 2. 功能范围（G2）

**做**：发起导出（PDF / PNG 图片包 / PPTX）、客户端本地渲染（Tauri 插件原生打印/截图 + pptxgenjs 文本层）、产物回传与云端台账、下载与重新下载；全屏演示模式（翻页、演讲者备注）。

**不做**：导出模板定制；打印；视频导出；在线分享链接。

## 3. 角色（G3）

创作者：发起导出、下载、放映。

## 4. 领域对象与关系（G4/G5）

- ExportTask（子流程）：格式/来源版本/状态/产物 key。
- 导出记录 = ExportTask 的终态视图（SUCCEEDED 实例列表）。
- 演示放映：无新领域对象，读取定稿版本快照（过程数据渲染）。

## 5. 业务字段（T1）

| 字段 | 说明 | 约束 |
|------|------|------|
| deckId / versionId | 归属与来源 | versionId=finalVersionId |
| exportFormat | 格式 | 枚举 PDF / IMAGES / PPTX（PPTX 标注 beta） |
| fileKey / fileSize | 产物 | 对象存储 key；下载凭证限时 |
| exportStatus | 状态 | QUEUED/RENDERING/SUCCEEDED/FAILED |

## 6. 被引用关系（T1a）

引用定稿版本与素材文件（渲染取用）。

## 7. 状态流转（T2）

ExportTask：QUEUED→SUCCEEDED（客户端上传产物）/FAILED（客户端上报）/CANCELLED；RENDERING 保留枚举兼容历史（api-delivery v1.3，ADR-015）。

## 8. 业务规则

1. 仅 FINALIZED 态创作物可导出/演示（守卫）。
2. 同格式重复导出直接新建任务（不缓存复用，素材可能更新——渲染以版本快照为准，实际可缓存，首期简化为不缓存）。
3. 下载凭证 30 分钟有效，可反复重新生成。
4. 演示模式读取 finalVersionId；进入演示全屏隐藏所有编辑入口。
5. 渲染以版本快照中的素材引用解析文件（素材已停用仍可解析，因停用不删文件）；v1.2：解析在客户端进行（素材限时 URL 直取，渲染源=演示渲染组件多页模式）。

## 9. 非功能与异常（N1/N2）

- 渲染在用户本机执行（内存不再受服务器约束）：PDF/图片渲染 ≤60s；PPTX 因版式还原复杂度允许 ≤5min 与更高的失败容忍（beta 标注）。
- 渲染失败保留错误信息（客户端上报 fail），本地可重试；产物回传上限 50MB（EXPORT_ARTIFACT_MAX_MB）；产物保留 30 天后清理（记录保留）。
- 服务器零渲染负载（1GB 小内存友好）；无服务端渲染超时监控，QUEUED 悬挂由用户 cancel/重试清理。

## 10. 历史与审计（N4）

导出记录持久化（格式/时间/来源版本/大小）；演示不记录。
