# PRD — 版本管理（C-04）

| 属性 | 值 |
|------|-----|
| 模块 | C-04 版本管理（AA v1.0） |
| 功能类型 | 业务流程类（版本树聚合 + 只读分析操作） |
| 版本 | v1.1 |
| 日期 | 2026-10-08 |

## 1. 业务目标（G1）

组织语言迭代的产物：自动留档不可变版本、树状谱系浏览、双版本对比、回退与分叉。让「每一句话的结果都可找回、可比较、可重来」。

## 2. 功能范围（G2）

**做**：版本自动留档（任务成功回调）、版本树浏览（分支/来源指令/时间）、任意版本预览、双版本对比（逐页差异高亮）、回退（移当前指针）、分叉（命名分支）。

**不做**：版本删除/编辑（不可变）；跨创作物版本合并；版本备注的手动标注（首期不做）。

## 3. 角色（G3）

创作者：浏览、预览、对比、回退、分叉。

## 4. 领域对象与关系（G4/G5）

聚合根「内容版本 DeckVersion」（独立聚合，树边=parentVersionId）；见 domain-model.md §2。

## 5. 业务字段（T1）

| 字段 | 说明 | 约束 |
|------|------|------|
| deckId | 所属创作物 | 必填 |
| versionSeq | 谱系内序号 | 创建时分配，只读 |
| branchName | 分支名 | 默认 main；≤50 字 |
| parentVersionId | 父版本 | 首版为空 |
| content | 内容快照 | 页面树 JSON（页面/块/文本/图片引用），只读 |
| sourceType | 来源 | 枚举 FULL_GENERATE / FULL_ADJUST / TARGETED_ADJUST |
| instructionSnapshot | 来源指令快照 | 指令文本/scope/品牌/素材/话术引用 |
| taskId | 来源任务 | 溯源 |

## 6. 被引用关系（T1a）

被 Deck.currentVersionId/finalVersionId、ExportTask、对比/分叉/演示引用。

## 7. 状态流转（T2）

版本本身无状态机（不可变）；回退/分叉改变 Deck 指针与活动分支（属 Deck 状态域，见 prd-deck §7）。

## 8. 业务规则

1. 版本一旦创建不可修改/删除（不可变性为产品级承诺）。
2. 回退不移除任何版本：等价于「以历史版本为基线继续」，若继续调整将产生 parent=该历史版本的新版本（同分支）。
3. 分叉必须命名分支（重名校验，同创作物内唯一）；分叉后活动分支切换。
4. 对比差异以页面为单位：结构变更/文本变更/图片变更三色标注。
5. 树视图默认展示活动分支，其余分支折叠。

## 9. 非功能与异常（N1/N2）

- 对比为实时计算（过程数据），版本 ≤ 数千时全量对比 <3s。
- 内容快照体积单版 ≤5MB（超出压缩图片引用为地址）。

## 10. 历史与审计（N4）

回退/分叉操作记录操作日志（操作前后指针值）。
