# D0 报告 — UI 推倒重来（2026-10-22）

## 需求原话
> 「例如这两个界面，为什么有一个卡片要长出来一点儿？所以我要求你UI这一块全部推倒重来，建立一个现代化、简约、用户友好的界面！」

## 「卡片长出来一点儿」诊断（两张截图：创作物管理 / 导出记录）
| # | 症状 | 根因（代码定位） |
|---|------|----------------|
| 1 | 列表卡底部亮白横条、比兄弟卡"长一截"；空表也有 | 表格 `scroll: { x: 'max-content' }`（DlListPage.vue:395）产生**原生横向滚动条**；全站无任何滚动条样式（grep 零命中）→ 暗色下原生白条贴卡片底边 |
| 2 | 表格内浅色竖线 | Antd 固定列（操作列 `fixed:'right'`）分界阴影，暗色 token 未覆盖 |
| 3 | 筛选区字段跳位、列被截断 | 查询 3 列网格 + max-content 列宽分配节奏问题 |
| 4 | 「感觉很乱」的结构根源 | 三卡堆叠（工具条卡/筛选卡/列表卡）+ 蓝竖条卡片标题 = 老式企业后台语言 |
